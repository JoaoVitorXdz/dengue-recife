Como funciona? Esta previsão usa o modelo XGBoost treinado com 520 semanas de dados reais de Recife (2015–2024). Os lag features (casos das semanas anteriores) são os preditores mais importantes, seguidos pela umidade e temperatura. O erro médio (MAE) do modelo é de 14.3 casos/semana.
